## Hi, I'm Rohan 👋

I'm a solo founder. I build web products, WordPress membership sites and AI tools that do real work.

### What I'm building

**[SahlQuote](https://sahlquote.com)** is a web app for UAE building-material suppliers. A contractor sends a bill of quantities as a PDF. SahlQuote reads it, turns it into checked item rows, matches each row to the supplier's own price list and gives back a draft priced quotation as an Excel file, in English or Arabic.

### What I work on

- **Web products:** from idea to a live app, built with AI coding help
- **WordPress and MemberPress:** membership sites, setup, fixes and custom features
- **AI setups:** chat assistants, document extraction and workflow automation
- **Motion and video:** product explainers and launch videos made in code (HyperFrames, Remotion, Three.js)
